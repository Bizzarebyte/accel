How it works

Tap Start engine to play the startup sound. After the startup sound finishes, the idle sound loops by default. As soon as the accelerometer detects any real acceleration, it crossfades into a separate rev sound; easing back off crossfades back to idle.

This uses the phone's accelerometer, so it reacts to changes in motion rather than measuring actual vehicle speed.

iPhone: Open this page in Safari. Tap Start engine and allow Motion & Orientation Access if prompted.

Motion sensor only. No GPS is used.
