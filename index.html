How it works

Tap Start engine to play the startup sound. The idle engine sound starts underneath the final part of the startup sound and fades in so there is no silent gap between them.

When the motion sensor detects sustained acceleration, the system smoothly crossfades from the idle sound into the rev sound. When acceleration decreases, it smoothly crossfades back to idle.

This uses the phone's motion sensor. It does not use GPS or measure actual vehicle speed.

iPhone: Open this page in Safari and tap Start engine. Allow Motion & Orientation Access if prompted.

Motion sensor only. No GPS is used.
