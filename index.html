How it works

Tap Start engine to play the startup sound. After the startup sound finishes, the engine sound begins looping and behaves like a race-car engine: acceleration raises the simulated RPM, while easing off lets the RPM fall gradually.

This uses the phone's accelerometer, so it reacts to changes in motion rather than measuring actual vehicle speed.

iPhone: Open this page in Safari. Tap Start engine and allow Motion & Orientation Access if prompted.

Motion sensor only. No GPS is used.
