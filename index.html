How it works

Tap Start engine to play the startup sound. The idle engine sound starts playing shortly before the startup sound ends, preventing a silence gap. When the motion sensor detects sustained acceleration, the system smoothly fades into the rev sound. When acceleration decreases, the rev sound smoothly fades back into the idle sound.

This uses the phone's motion sensor. It does not use GPS or measure actual vehicle speed.

iPhone: Open this page in Safari and tap Start engine. Allow Motion & Orientation Access if prompted.

Motion sensor only. No GPS is used.
