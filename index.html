How it works

Tap Start engine to play the startup sound. When startup finishes, the idle engine sound begins looping. When the phone detects sustained acceleration, the system crossfades from idle into the rev sound. When acceleration decreases, it crossfades back to idle.

This uses the phone's motion sensor. It does not use GPS or measure actual vehicle speed.

iPhone: Open this page in Safari and tap Start engine. Allow Motion & Orientation Access if prompted.

Motion sensor only. No GPS is used.
