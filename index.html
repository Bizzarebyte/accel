How it works

Tap Start engine to play the startup sound. After startup, the idle sound loops automatically. When the motion sensor detects sustained acceleration, the engine smoothly crossfades into the rev sound. When acceleration drops back down, it crossfades to idle.

This uses the phone's accelerometer, so it reacts to changes in motion rather than measuring actual vehicle speed.

iPhone: Open this page in Safari. Tap Start engine and allow Motion & Orientation Access if prompted.

Motion sensor only. No GPS is used.
