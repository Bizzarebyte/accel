``` How it works ```

``` Tap Start engine to play the startup sound. Near the end of the startup sound, the idle engine sound fades in underneath it so there is no gap. When the motion sensor detects sustained acceleration, the system smoothly crossfades from idle into the rev sound. When acceleration decreases, it smoothly crossfades back to idle. ```

``` This uses the phone's motion sensor. It does not use GPS or measure actual vehicle speed. ```

``` iPhone: Open this page in Safari and tap Start engine. Allow Motion & Orientation Access if prompted. ```

Motion sensor only. No GPS is used.
